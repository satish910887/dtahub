About Text Diff Checker

Text Diff Checker compares two versions of a text and highlights added and removed lines or words. You can ignore case or extra spaces. It uses its own comparison method and runs fully in your browser.

How to use

  1. Type or paste your text into the box.
  2. Tap the action button for the result.
  3. Copy the result with one tap.

Good to know

Use line mode for code and lists, word mode for sentences.
