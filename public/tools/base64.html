About Base64 Tool

Base64 Tool encodes and decodes text safely, including Hindi and emoji, with URL-safe output, optional padding removal and 76-character line wrapping. Turn any file or image into Base64 or a data URI, or decode Base64 back into a file with the type detected for you.

How to use

  1. Type or paste your text into the box.
  2. Tap the action button for the result.
  3. Copy the result with one tap.

Good to know

Tick URL-safe when the result goes into a link or a token.
