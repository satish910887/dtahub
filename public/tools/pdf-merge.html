Merge PDF

Merge.

    Your files are processed on your device and never uploaded. Limits: 30 MB per image, 50 MB per PDF.

    About Merge PDF

    Merge PDF joins several PDF files into one. See each file's page count, choose which pages of a file to include, reorder by dragging or with arrows, sort by name or size and name the output. A damaged or protected file is flagged before merging.

    How to use

    1. Tap the box (or drag a file onto it) and choose your file.
    2. Adjust the options if you need to.
    3. Download the result. Your file never leaves your device.

    Good to know

    Type a range like 1-3, 5 next to a file to include only those pages.
