CSV ⇄ JSON Converter

Convert CSV to JSON or JSON to CSV, with quotes and commas handled properly.

Your text stays in your browser. Nothing is stored or sent anywhere.

About CSV ⇄ JSON Converter

CSV and JSON Converter changes a spreadsheet style CSV into JSON and a JSON list back into CSV. It detects commas, semicolons, tabs or pipes, handles quoted cells and line breaks inside cells, can turn numbers and true or false into real values, and lets you copy the result or download it as a file. It runs on your device, so your data is never uploaded.

How to use

  1. Type or paste your text into the box.
  2. Tap the action button for the result.
  3. Copy the result with one tap.

Good to know

Check the first row: it becomes the JSON key names.
