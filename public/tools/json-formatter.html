About JSON Formatter

 
JSON Formatter validates, beautifies and minifies JSON with 2, 4 or tab indent and optional key sorting. Errors show the line and column, Try to fix repairs common mistakes, and the tree view lets you collapse nodes and tap a key to copy its JSONPath. Convert to CSV, load a file and download the result.

 
How to use

 
  1. Type or paste your text into the box.
  2. Tap the action button for the result.
  3. Copy the result with one tap.

 
Good to know

 
Tap any key in Tree view to copy its JSONPath.
