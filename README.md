# DTAhub – Your Everyday Digital Toolkit

Free online tools (PDF, image, text, developer, calculators, SEO) that run **inside the visitor's browser**. No server, no sign-up, no paid services. Hosted on Cloudflare (Workers static assets).

## Structure
```
public/                 the whole website (this folder is deployed)
  index.html            homepage (rendered from the registry by js/app.js)
  tools/<id>.html       one page per tool
  category/<id>/        category pages (generated)
  js/tools-data.js      CENTRAL REGISTRY: tools, categories, FAQ, icons
  js/tool.js            shared shell: header wiring, palette (Ctrl+K), favourites, toasts, drag & drop
  js/config.js          public settings (contact form key)
  css/style.css         design system   |  css/tool.css  tool workspace styles
  sw.js, manifest.webmanifest, sitemap.xml, robots.txt, _headers   (generated by the build script)
scripts/build.mjs       keeps SEO, JSON-LD, breadcrumbs, header, footer, sitemap, offline cache in sync
scripts/make-icons.py   regenerates icons / social image
scripts/serve.mjs       local preview (mimics Cloudflare clean URLs)
```

## Add a new tool (3 steps)
1. Create `public/tools/<id>.html` (copy a similar tool; keep `<h1>`, `<p class="lead">`, a `<main class="tw">`, and the `<script src="/js/tool.js">` line).
2. Add ONE entry to `TOOLS` in `public/js/tools-data.js` (id, cat, kind, en/hi names, descriptions, about, tip, related, add `featured: 1` for Top picks). Add an icon key to `ICONS` with the same id.
3. Run `node scripts/build.mjs`, then commit and push. The directory, category page, sitemap, SEO tags, related tools and offline cache all update automatically.

## Build and preview
```
node scripts/build.mjs          # needs Node 18+ (Termux: pkg install nodejs)
node scripts/serve.mjs 8787     # open http://localhost:8787
```
After you buy a domain: `SITE_URL=https://yourdomain.com node scripts/build.mjs` (also change `SITE` in tools-data.js).

## Contact form
Get a free access key at https://web3forms.com and paste it into `public/js/config.js`. Until then the form is disabled and shows a GitHub-issue fallback.

## Rules this project follows
Original code and design, free and open-source only, no paid APIs, no tracking, files never uploaded. Third-party code: `qrcode-generator` (MIT), `pdf-lib` (MIT), both stored locally in `public/js/vendor/`.
